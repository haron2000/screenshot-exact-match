# AZ-Ready Demo Flow

## Recommended Demo Path

Use this sequence for the hackathon video demonstration:

1. Open the AZ-Ready landing page.
2. Start the diagnostic assessment.
3. Answer several questions, including at least one incorrect answer.
4. Show the immediate explanation and learning feedback.
5. Complete the assessment or move to the results screen.
6. Highlight the overall readiness score.
7. Show the strongest and weakest learning areas.
8. Open targeted practice.
9. Show how practice focuses on areas where the learner needs improvement.
10. Return to the dashboard and close with the core message:

> Know what you know. Fix what you don't.

## Demo Story

The demo should communicate this product loop:

**Assess → Understand → Identify Weaknesses → Practise → Improve**

Do not attempt to demonstrate every screen. Prioritise the flow that proves the product's main differentiator: using assessment results to guide what the learner should practise next.

## Suggested Closing

AZ-Ready is designed to do more than tell learners their score. It helps them understand what to work on next.
